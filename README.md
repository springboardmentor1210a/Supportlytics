# Supportlytics — IT Support Team Performance Analytics

## Project

Supportlytics is an IT support analytics platform designed to transform raw support-ticket data into meaningful operational insights.

The project analyzes support tickets across categories, priorities, channels, regions, support teams, clusters, resolution performance, and customer satisfaction.

## Problem

IT support teams handle large volumes of tickets across different categories, priorities, regions, and support teams.

Without centralized analytics, it can be difficult to identify:

- High-volume issue categories
- Priority patterns
- Resolution performance
- Regional differences
- Customer satisfaction trends

## Objectives

The project aims to:

- Analyze support-ticket data
- Identify recurring issue patterns
- Evaluate resolution performance
- Analyze customer satisfaction
- Perform clustering and similarity analysis
- Build an interactive Power BI dashboard

Analyzed regional ticket distribution, resolution time, customer satisfaction, team performance, department performance, and priority-based performance.
