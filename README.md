Supportlytics — Optimizing IT Support Team Performance Using Analytics
📋 Project Overview
The objective of this project is to analyze IT support ticket data to identify key performance trends, optimize resolution times, and enhance service efficiency through data analysis and visualization. The goal is to uncover patterns in customer requests, technical issues, and support performance metrics to recommend improvements in workflow and resource allocation.  

🚀 Key Modules Implemented
Module 1: Data Initialization & Setup — Loaded and inspected the IT support dataset (df.shape: 10,000 rows, 30 columns) to understand schemas and initial distribution metrics.

Module 2: Data Cleaning & Feature Engineering — Handled missing fields, extracted custom columns (such as Resolution_Time), and categorized performance buckets.

Module 3: Exploratory Data Analysis (EDA) — Analyzed ticket distributions across types (Incident, Question, Problem), priorities, and categories (Technical, Billing, Account Management).

Module 4: Cluster and Similarity Analysis — Studied issue clusters (Cluster_ID) and measured similarity scores to evaluate resolution rates.

Module 5: Performance Insights & Optimization — Compared resolution times across global regions and priorities to detect performance gaps.

Module 6 & 7: Visualization & Streamlit Dashboard — Developed interactive dashboards utilizing Python libraries to present executive performance metrics.

🛠️ Tech Stack
Language: Python

Data Manipulation & Analysis: Pandas, NumPy

Visualization: Matplotlib, Seaborn, Plotly

Dashboard Interface: Streamlit
